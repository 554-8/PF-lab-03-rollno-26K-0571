Introduction

This lab is an introduction to C programming and GitHub. It covers creating and managing repositories, writing and formatting documentation using markdown , and working with important GitHub features such as branches, pull requests , commits etc. the lab also introduces basic C programming concepts and helps students to manage and document their programming work on GitHub. 

Objectives

1. To understand the basic use of GitHub.
2. To practice writing C programs.
3. To understand the use of C programming concepts.
4. To develop basic programming and problem-solving skills.
5. To practice GitHub features. 

C Topics Covered in Lab 3

* File saving 
* Syntax of the language 
* data types 
* format specifiers
* escape sequences
* precision
